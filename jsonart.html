JSON Toolkit.

Developers spend an immense amount of time dealing with JSON payloads—formatting configurations, debugging API structures, validating syntax errors, and testing REST endpoints. JSONArt is a modern, high-performance web-based toolkit that unifies these essential utilities into a single, cohesive developer platform.

I designed and engineered the entire application, prioritizing **lightning-fast client-side processing, strict data privacy, and a responsive glassmorphism UI**. The tool processes all JSON manipulations locally inside the user's browser, ensuring absolute security for sensitive API tokens and keys. It features an interactive AST tree viewer, a real-time syntax validator, a side-by-side visual diff compare engine, and a complete API testing client.

System Architecture

JSONArt is engineered as a lightweight, framework-free single-page application (SPA). By leveraging vanilla modern JavaScript (ES6+) instead of heavy framework runtimes, the toolkit achieves sub-millisecond processing speeds, zero package overhead, and instant page loads.

The application structure utilizes a unidirectional data processing pipeline: raw user input is captured, fed into a specialized client-side AST parser, validated against strict RFC-8259 schemas, and then distributed to the respective rendering engines (Interactive DOM Tree, Diff Highlighter, or API Runner).

Core Feature Implementations

JSONArt is designed around a unified workspace. Instead of using disparate websites to validate, format, compare, or run requests, developers can cycle through features with a single, synchronized JSON state.

  • Collapsible JSON AST Tree Viewer

    Constructs an interactive DOM tree from raw JSON payloads. Each key-value pair is parsed and color-coded based on its data type (Strings, Numbers, Booleans, Nulls). Nodes are collapsible, allowing developers to collapse or expand large nested arrays and objects instantly, with integrated "Copy Path" buttons for easy schema referencing.

  • Strict Syntax Validator with Error Location

    Standard browser JSON parsers only output a generic "Unexpected token" message. JSONArt implements an iterative, character-level syntax validation pipeline. In case of syntax failures (e.g., missing commas, unquoted keys, trailing commas), it highlights the exact line number, column index, and character snippet, drastically reducing debugging time.

  • Side-by-Side Visual Diff Compare Engine

    Implements a custom text-differencing algorithm operating locally. It matches two JSON objects line-by-line, accounting for key order variations, and renders a side-by-side split screen showing additions (highlighted in emerald green) and deletions (highlighted in ruby red). Key ordering is programmatically normalized so structural comparison is not skewed by key order discrepancies.

  • CORS-Aware REST API Testing Client

    Integrates a robust client-side HTTP runner enabling developers to trigger GET, POST, PUT, DELETE, PATCH requests directly from the dashboard. Developers can customize headers, adjust query parameters, and embed JSON payloads (from the active editor) into the request body, inspecting the response time, status codes, and headers in real time.

Technical Challenges & Solutions

1. Layout Thrashing on Large Files

  • Challenge: Rendering huge collapsible JSON trees (e.g., 5MB+ logs) creates tens of thousands of DOM nodes. This exhausts browser memory and causes severe layout scrolling lag.
  • Solution: Implemented **progressive DOM rendering** and lazy-expansion nodes. Nested children are only generated in the DOM when a parent node is explicitly expanded by the user, keeping the initial render and active DOM footprint under 1,000 active nodes.

2. Data Privacy & CORS Barriers

  • Challenge: Developer data often contains sensitive production API keys, customer credentials, and database schemas. Traditional online parsers upload data to servers. Additionally, browser API clients face strict CORS constraints.
  • Solution: Engineered JSONArt to run **100% locally**. Files are parsed completely client-side. For the API client, custom CORS bypass configurations and descriptive pre-flight diagnostics are embedded to help developers configure their API gateways properly.
